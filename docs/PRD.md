# مەھسۇلات تەلەپلىرى ھۆججىتى (PRD)
## قارلۇق ئۆگىنىش ياردەمچىسى (Karluk Learning Assistant)

**نەشرى:** 1.0.0  
**سۇپا:** Google Chrome Extension (Manifest V3) + تور كۆرگۈچ سىناق مۇھىتى  
**تىل ۋە يۆنىلىش:** ئۇيغۇرچە (`dir="rtl"`)  
**مەخپىيەتلىك دەرىجىسى:** %100 يەرلىك ساقلاش، نۆل ئىز قوغلاش (Zero Telemetry)

---

## 1. قىسقىچە مەزمۇن ۋە مەقسەت

**«قارلۇق ئۆگىنىش ياردەمچىسى»** ئوقۇغۇچىلار، تەتقىقاتچىلار ۋە بىلىم ئىگىلىرىنىڭ ھەر قانداق كىتاب، دەرسلىك ياكى ئىلمىي مەزمۇننى تەرتىپلىك **30 تەپسىلىي سۇئال-جاۋاب** شەكلىدە قايتا-قايتا پىششىقلاپ ئۆگىنىشىگە ياردەم بېرىدىغان ئەقلىي ياردەمچى قىستۇرمىسىدۇر.

ئىشلەتكۈچى خالىغان سۈنئىي ئەقىل (AI) مودېلىغا مەخسۇس تەييارلانغان پىرۇمپىت بىلەن كىتاب مەزمۇنىنى بېرىپ، قېلىپلاشقان JSON ھۆججىتىگە ئېرىشىدۇ؛ ئاندىن بۇ JSON نى قىستۇرمىغا بىر قېتىم يۈكلىگەندىن كېيىن، مەلۇماتلار كومپيۇتېردا مەڭگۈلۈك ساقلىنىپ قالىدۇ، ھەر بىر كىتاب ئايرىم كىتاپخانا شەكلىدە باشقۇرۇلىدۇ ۋە خالىغان ۋاقىتتا تور كۆرگۈچ ئېچىلغاندا كۈندىلىك ئەسكەرتىش چىقىرىپ بېرىدۇ.

---

## 2. مەھسۇلات نىشانى ۋە پىرىنسىپلىرى

1. **تولۇق مۇستەقىللىق ۋە مەخپىيەتلىك:** ھېچقانداق سىرتقى مۇلازىمېتىر، Google Analytics، خىتاي شىركەتلىرىنىڭ API ياكى CDN مۇلازىمەتلىرى ئىشلىتىلمەيدۇ. بارلىق كىتابلار ۋە ئىلگىرىلەش ئەھۋالى پەقەت `chrome.storage.local` دا ساقلىنىدۇ.
2. **ئۇيغۇرچە مەتبەئە سۈپىتى ۋە مىللىي سالاھىيەت:** بارلىق ئاتالغۇلاردا مۇستەقىللىق ۋە شەرقىي تۈركىستان مەدەنىيەت-ئەخلاق مىزانلىرى قاتتىق ساقلىنىدۇ.
3. **سىغىمچانلىق ۋە مەڭگۈلۈك ساقلاش:** بىر قېتىم يۈكلەنگەن JSON ھۆججىتى يوقاپ كەتمەيدۇ؛ ھەر بىر كىتاب ئايرىم ئوبوروت ۋە ساقلاش بۆلىكىدە تۇرىدۇ.
4. **ئەمەلىي كۈندىلىك ئادەت شەكىللەندۈرۈش:** تور كۆرگۈچ (Chrome) ھەر قېتىم ئېچىلغاندا ئەسكەرتىش چىقىرىش ياكى ئىشلەتكۈچى خالىسا تەڭشەك ئارقىلىق ئېتىۋېتىش مۇمكىنلىكى.

---

## 3. نىشانلىق ئىشلەتكۈچىلەر ۋە ئىشلىتىش قەدەملىرى

### ئىشلىتىش جەريانى (User Journey)
1. **پىرۇمپىت تەييارلاش:** ئىشلەتكۈچى قىستۇرمىنىڭ ئەڭ ئاستىدىكى **«ئىئاي ئۈچۈن پىرۇمپىت تەييارلاش»** كۇنۇپكىسىنى باسىدۇ. پىرۇمپىت ئاپتوماتىك كۆچۈرۈلىدۇ (ھەمدە كۆزنەكتە كۆرگىلى بولىدۇ).
2. **30 سۇئال-جاۋاب ھاسىل قىلىش:** ئىشلەتكۈچى بۇ پىرۇمپىتنى خالىغان سۈنئىي ئەقىل مودېلىغا تاشلاپ، كىتاب ياكى دەرسلىك مەزمۇنىنى قوشۇپ بېرىدۇ. مودېل دەل **30 دانە ئەڭ مۇھىم ۋە تەپسىلىي سۇئال-جاۋاب** قايتۇرىدۇ.
3. **كىتاب قوشۇش (JSON يۈكلەش):** ئىشلەتكۈچى **«كىتاپ قوشۇش»** كۇنۇپكىسى ئارقىلىق `.json` ھۆججىتىنى يۈكلەيدۇ ياكى JSON تېكىستىنى چاپلايدۇ. كىتاب ئىسمى ئاپتوماتىك (ياكى ئىشلەتكۈچى كىرگۈزگەن ئىسىم بويىچە) ئايرىم ساقلىنىدۇ.
4. **ئەسكەرتىملەر ۋە ئۆگىنىش:** **«ئەسكەرتىملەر»** كارتىسىدا سۇئال كۆرۈنىدۇ؛ ئىشلەتكۈچى جاۋابنى ئېچىپ تەكشۈرىدۇ، «ئۆگەندىم» دەپ بەلگە سالىدۇ، ياكى كېيىنكى سۇئالغا ئۆتىدۇ.
5. **تور كۆرگۈچ ئېچىلغاندا ئەسكەرتىش:** **«تەڭشەك»** ستونىدا ئەسكەرتىش ۋىكليۇچاتېلى ئوچۇق بولسا، ھەر قېتىم Chrome ئېچىلغاندا تاللانغان كىتابتىن بىر مۇھىم سۇئال ئەسكەرتىش شەكلىدە چىقىدۇ؛ خالىسا بىر بېسىش بىلەن ئېتىۋېتىدۇ.
6. **كىتاب چىقىرىش (Export / Manage):** **«كىتاپ چىقىرىش»** كۇنۇپكىسى ئارقىلىق خالىغان كىتابنى JSON ھۆججىتى قىلىپ زاپاس ساقلىغىلى ياكى ئۆچۈرگىلى بولىدۇ.

## 5. كۆرۈنۈش ۋە مەتبەئە ئۆلچىمى

- كۆزنەك كەڭلىكى: `360px` – `380px`، سىزىقلىق/ئالما ئۇسلۇبىدىكى **Liquid Glass** سۈزۈك ئەينەك ئۇسلۇبى.
- ئوڭدىن سولغا (`dir="rtl"`)، كۆپ قۇرلۇق مەزمۇن ئىككى تەرەپكە تەڭلەنگەن (`justify`) ۋە بىرىنچى قۇرى `1.75em` ئىچىدىن باشلانغان بولىدۇ.
- يۇقىرى سولدا قورال ئىسمى، يۇقىرى ئوڭدا لوگو، ئوڭ ياندا تىك «تەڭشەك» بالدىقى، ئاساسىي رايوندا «ئەسكەرتىملەر»، «كىتاپ قوشۇش»، «كىتاپ چىقىرىش» ۋە «ئىئاي ئۈچۈن پىرۇمپىت تەييارلاش» كۇنۇپكىلىرى ئورۇنلىشىدۇ.

---

## 6. غەيرىي ئىقتىدار تەلەپلىرى (Non-Functional Requirements)

- **بىخەتەرلىك:** XSS دىن ساقلىنىش ئۈچۈن `innerHTML` ئىشلىتىلمەيدۇ؛ قاتتىق CSP قوللىنىلىدۇ.
- **مۇقىملىق:** بارلىق مەشغۇلاتلار `try/catch` بىلەن قوغدىلىدۇ؛ كاشىلا چىققان JSON ھۆججەت مەۋجۇت كىتابلارغا زىيان سالمايدۇ.
- **سۈرئەت:** كۆزنەك ئېچىلىشى `< 100ms`، بارلىق ھەرىكەتلەر يەرلىك بولغاچقا تور تېزلىكىگە تايانمايدۇ.
