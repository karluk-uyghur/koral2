# كۆرۈنۈش ۋە ئۇسلۇب كۆرسەتمىسى (UI Style Guide)

بۇ ھۆججەت ئۇيغۇرچە (`dir="rtl"`) كىچىك ئەپ ئۈچۈن تۈزۈلگەن بولۇپ، **سۈزۈك كىرىستال ئەينەك (Liquid Glass / Tactile Glassmorphism)** ئۇسلۇبىنى ئاساس قىلىدۇ. يۇمشاق كۈلرەڭ ئارقا كۆرۈنۈش، قېلىن يالتىراق ئەينەك گىرۋەكلىرى، سۇس رەڭلىك نۇر سۇنۇش ئۈنۈمى ۋە يۇقىرى سېلىشتۇرمىلىق رەڭلەر ئارقىلىق زامانىۋى، پاكىز ۋە سېزىمچان كۆرۈنۈش ھاسىل قىلىنىدۇ.

---

## 1. رەڭ تاختىسى (Color Palette)

ئەينەك ئۇسلۇبىنىڭ سۈزۈكلۈكىنى گەۋدىلەندۈرۈش ئۈچۈن ئارقا كۆرۈنۈش سوغۇق ۋە تىنچ رەڭدە، مۇھىم ھەرىكەت ئېلېمېنتلىرى بولسا جانلىق ۋە نۇرلۇق رەڭلەردە تاللىنىدۇ.

| تۈرى | نامى | HEX كودى | ئىشلىتىش ئورنى |
| :--- | :--- | :--- | :--- |
| **ئاساسىي (Primary)** | ئىللىق ئاپېلسىن (باشلىنىش) | `#F05A28` | ئاساسىي كۇنۇپكا، مۇھىم ھەرىكەت چاقىرىقى |
| **ئاساسىي (Gradient)** | قۇياش ئاپېلسىنى (ئاخىرلىشىش) | `#F78C2B` | ئاساسىي كۇنۇپكا تەدرىجىي رەڭگى (Gradient) |
| **قوشۇمچە ئالاھىدە (Accent)** | سۈزۈك كۆك | `#1F75FE` | ئالاھىدە تەۋسىيە كۇنۇپكىسى، ئاكتىپ ھالەت |
| **قوشۇمچە (Secondary)** | سۈزۈك ئەينەك ئاق | `#F4F7FB` | قوشۇمچە كۇنۇپكا، كارتا يۈزى (`rgba(255, 255, 255, 0.55)` بىلەن) |
| **ئەينەك نۇر قايتۇرۇش** | سۇس مۇز كۆك | `#CFE8FF` | ئەينەك گىرۋەك ۋە يېنىك نۇر سۇنۇش سايىسى |
| **ئارقا كۆرۈنۈش (Background)** | سوغۇق ئوچۇق كۈلرەڭ | `#E4E7EC` | بەتنىڭ ئاساسىي ئارقا كۆرۈنۈشى |
| **ئارقا كۆرۈنۈش (Surface)** | سۇس كۈلرەڭ يۈز | `#EEF0F4` | قاتلاملىق رايونلار ۋە تەگلىك يۈزى |
| **ئاساسىي تېكىست** | قېنىق كۆمۈر رەڭ | `#1A1E24` | ماۋزۇ ۋە ئاساسىي تېكىستلەر |
| **قوشۇمچە تېكىست** | ئوتتۇرا كۈلرەڭ | `#555D6B` | چۈشەندۈرۈش، ياردەمچى تېكىست، ئىزدەش كۆرسەتمىسى |
| **ئەكس تېكىست (On Primary)** | ساپ ئاق | `#FFFFFF` | رەڭلىك (ئاپېلسىن، كۆك، يېشىل) كۇنۇپكا ئۈستىدىكى تېكىست |
| **خاتالىق (Error)** | يۇمشاق قىزىل | `#E03E36` | خاتالىق ئۇچۇرى، ئۆچۈرۈش كۇنۇپكىسى، ئاگاھلاندۇرۇش گىرۋىكى |
| **ئوڭۇشلۇق (Success)** | زۇمرەت يېشىل | `#1FA982` | تاماملىنىش ھالىتى، ئېچىلغان ۋىكليۇچاتېل (Toggle)، تاللانغان بەلگە |

## 2. خەت نۇسخىسى ۋە چوڭلۇقى (Typography)

ئۇيغۇرچە يېزىقنىڭ ئۇلىنىش ئالاھىدىلىكى ۋە ئېنىق ئوقۇلۇشى ئۈچۈن **`UKIJ Tuz`** ياكى **`Alkatip Tor`** خەت نۇسخىسى تەۋسىيە قىلىنىدۇ. ئەرەب يېزىقى ئاساسىدىكى خەتلەر لاتىن خەتلەرگە قارىغاندا سەل كىچىك كۆرۈنىدىغان بولغاچقا، ئاساسىي خەت چوڭلۇقى ۋە قۇر ئارىلىقى سەل كەڭرەك تەڭشىلىدۇ.

### خەت قاتارى (Font Stack)
```css
font-family: "UKIJ Tuz", "Alkatip Tor", "Noto Naskh Arabic", system-ui, sans-serif;
```

### چوڭلۇق، قېلىنلىق ۋە قۇر ئارىلىقى

| قاتلام | چوڭلۇقى (`font-size`) | قېلىنلىقى (`font-weight`) | قۇر ئارىلىقى (`line-height`) | ئىشلىتىلىشى |
| :--- | :--- | :--- | :--- | :--- |
| **چوڭ ماۋزۇ (H1)** | `24px` (`1.5rem`) | `700` (قېلىن) | `1.5` | بەتنىڭ ئاساسىي ماۋزۇسى |
| **كارتا ماۋزۇسى (H2)** | `19px` (`1.1875rem`) | `600` (ئوتتۇرا قېلىن) | `1.55` | كارتا ۋە كۆزنەك ماۋزۇلىرى |
| **ئاساسىي تېكىست (Body)** | `16px` (`1rem`) | `400` (نورمال) | `1.7` | ئادەتتىكى مەزمۇن، كىرگۈزۈش رامكىسى، تىزىملىك |
| **كۇنۇپكا تېكىستى** | `15px` (`0.9375rem`) | `500` (يېنىك قېلىن) | `1.4` | بارلىق كۇنۇپكا ۋە بەلگىچىلەر |
| **كىچىك تېكىست (Caption)** | `13px` (`0.8125rem`) | `400` (نورمال) | `1.6` | چۈشەندۈرۈش، ۋاقىت، ياردەمچى ئۇچۇر |

### ئۇيغۇرچە (`dir="rtl"`) خەت قائىدىلىرى
* **ھەرپ ئارىلىقىنى ئىشلەتمەسلىك:** `letter-spacing: 0;` بولۇشى شەرت. ئەگەر قىممەت بېرىلسە ئۇيغۇرچە ئۇلانما ھەرپلەر ئۈزۈلۈپ كېتىدۇ.
* **رەقەم توغرىلىنىشى:** سان ۋە جەدۋەللەردە `font-variant-numeric: tabular-nums;` ئىشلىتىلىدۇ.
* **تېكىست سىغدۇرۇش:** كۇنۇپكىلاردا تېكىست سۇنۇپ كەتمەسلىكى ئۈچۈن `white-space: nowrap;` قوللىنىلىدۇ.

## 3. شەكىل: گىرۋەك يۇمىلاقلىقى، كۆلەڭگە ۋە ئارىلىق

بۇ ئۇسلۇبنىڭ يادرولۇق ئالاھىدىلىكى — **تولۇق يۇمىلاق (كاپسۇل) شەكىل**، **ئۈستى يالتىراق ئەينەك قاتلىمى** ۋە **يۇمشاق رەڭلىك نۇر كۆلەڭگىسى**.

### گىرۋەك يۇمىلاقلىقى (Border Radius)
* **كاپسۇل شەكىل (Pill):** `9999px` — كۇنۇپكا، ئىزدەش رامكىسى، بەتكۈچ (Tab)، قىسقا ئۇقتۇرۇش (Toast)، ۋىكليۇچاتېل (Toggle).
* **كارتا ۋە كۆزنەك (Card / Modal):** `22px` — مەزمۇن كارتىلىرى ۋە قاڭقىما كۆزنەكلەر.
* **چاسا سىنبەلگە كۇنۇپكىسى:** `14px` — پەقەت سىنبەلگە بار كىچىك كۇنۇپكىلار.
* **تاللاش كاتەكچىسى (Checkbox):** `6px` — كىچىك تاللاش رامكىلىرى.

### ئەينەك قاتلىمى ۋە گىرۋەك سىزىقى (Glass & Rim)
* **تۇتۇقلاشتۇرۇش:** `backdrop-filter: blur(18px) saturate(160%);`
* **تاشقى گىرۋەك سىزىقى:** `1.5px solid rgba(255, 255, 255, 0.78)`
* **ئىچكى يالتىراقلىق (Specular Highlight):** ئۈستۈنكى قىرغا كۈچلۈك ئاق نۇر، ئاستىنقى قىرغا سۇس كۆكۈش/كۈلرەڭ نۇر قايتۇرۇش بېرىلىدۇ.

### كۆلەڭگە سىستېمىسى (Shadows & Caustics)
كۆلەڭگىلەر ئىككى قاتلامدىن تۈزۈلىدۇ: يۇمشاق تەبىئىي كۆلەڭگە + ئەينەكتىن ئۆتكەن سۇس رەڭلىك نۇر (Caustic Glow).

* **ئەينەك كارتا / قوشۇمچە ئېلېمېنت كۆلەڭگىسى:**
  ```css
  box-shadow:
    0 10px 24px -6px rgba(26, 30, 36, 0.14),
    0 4px 12px -2px rgba(130, 190, 255, 0.22),
    inset 0 2px 3px rgba(255, 255, 255, 0.90),
    inset 0 -2px 4px rgba(160, 175, 200, 0.25);
  ```
* **ئاساسىي رەڭلىك (ئاپېلسىن) كۇنۇپكا كۆلەڭگىسى:**
  ```css
  box-shadow:
    0 12px 24px -6px rgba(240, 90, 40, 0.42),
    0 4px 10px -2px rgba(247, 140, 43, 0.30),
    inset 0 2px 4px rgba(255, 255, 255, 0.72),
    inset 0 -2px 5px rgba(175, 45, 10, 0.35);
  ```
* **ئوڭۇشلۇق (يېشىل) ئېلېمېنت كۆلەڭگىسى:**
  ```css
  box-shadow:
    0 8px 18px -5px rgba(31, 169, 130, 0.38),
    inset 0 2px 3px rgba(255, 255, 255, 0.65);
  ```

### ئارىلىق ۋە بوشلۇق (Spacing & Padding)
بوشلۇقلار `4px` لىق ئاساسىي بىرلىك بىلەن ھېسابلىنىدۇ. **`dir="rtl"` ئۈچۈن چوقۇم مەنتىقىلىق خۇسۇسىيەتلەر (`padding-inline`, `margin-inline`, `gap`) ئىشلىتىلىدۇ.**

* **ئېلېمېنت ئىچىدىكى ئارىلىق (Padding):**
  * چوڭ كۇنۇپكا: `padding-block: 12px; padding-inline: 28px;`
  * ئوتتۇرا كۇنۇپكا / بەتكۈچ: `padding-block: 10px; padding-inline: 22px;`
  * ئىزدەش ۋە كىرگۈزۈش رامكىسى: `padding-block: 12px; padding-inline: 18px;`
  * كارتا ئىچكى بوشلۇقى: `20px` (چوڭ كارتىلاردا `24px`)
* **ئېلېمېنتلار ئارىسىدىكى بوشلۇق (Gap):**
  * سىنبەلگە بىلەن تېكىست ئارىسى: `8px` – `10px`
  * يانداش كۇنۇپكىلار ئارىسى: `12px` – `16px`
  * كارتا ۋە بۆلەكلەر ئارىسى: `20px` – `24px` (كۆلەڭگە ۋە نۇر ئۈنۈملىرى بىر-بىرىگە چاپلىشىپ قالماسلىقى ئۈچۈن كەڭ بوشلۇق قالدۇرۇلىدۇ)

## 4. كۇنۇپكا ۋە كارتا ئۇسلۇبى (Components)

### ئاساسىي كۇنۇپكا (Primary Button)
* **تەگلىك:** `linear-gradient(180deg, #F78C2B 0%, #F05A28 60%, #DC4416 100%)`
* **تېكىست رەڭگى:** `#FFFFFF`
* **گىرۋەك:** `1.5px solid rgba(255, 225, 200, 0.7)`
* **شەكىل:** تولۇق يۇمىلاق (`border-radius: 9999px`)، ئۈستۈنكى يېرىمىدا سۈزۈك ئاق يالتىراق نۇر قاتلىمى بولىدۇ.

### قوشۇمچە ئەينەك كۇنۇپكا (Secondary Glass Button)
* **تەگلىك:** `linear-gradient(180deg, rgba(255, 255, 255, 0.72) 0%, rgba(238, 243, 250, 0.45) 100%)`
* **تېكىست رەڭگى:** `#1A1E24`
* **گىرۋەك:** `1.5px solid rgba(255, 255, 255, 0.85)`
* **ئالاھىدىلىك:** `backdrop-filter: blur(16px)` ئارقىلىق ئارقىسىدىكى يۈزنى يېنىك تۇتۇقلاشتۇرۇپ كۆرسىتىدۇ.

### ئىزدەش ۋە كىرگۈزۈش رامكىسى (RTL Input)
* **تۈزۈلۈشى (`dir="rtl"`):** ئىزدەش سىنبەلگىسى **ئوڭ تەرەپتە**، قوشۇمچە ھەرىكەت كۇنۇپكىسى (مەسىلەن `+` ياكى تازىلاش) **سول تەرەپتە**، كىچىك سۈزۈك ئايرىش سىزىقى بىلەن ئورۇنلىشىدۇ.
* **تەگلىك:** `rgba(255, 255, 255, 0.58)`، فوكۇس بولغاندا (`:focus-within`) گىرۋەك رەڭگى `#1F75FE` ياكى `#F05A28` غا يۇمشاق ئۆزگىرىدۇ.

### ئەينەك كارتا (Glass Card)
* **تەگلىك:** `linear-gradient(145deg, rgba(255, 255, 255, 0.68) 0%, rgba(235, 241, 248, 0.42) 100%)`
* **يۇمىلاقلىقى:** `22px`
* **گىرۋەك:** `1.5px solid rgba(255, 255, 255, 0.80)`
* **تەرتىپلىنىشى (`dir="rtl"`):** كارتا ماۋزۇسى ئوڭغا توغرىلىنىدۇ؛ ئەگەر تاقاش سىنبەلگىسى (`×`) بولسا يۇقىرى سول بۇلۇڭغا قويۇلىدۇ. ئىچكى كۇنۇپكىلار كارتا كەڭلىكىگە ماسلىشىپ، ئاستىنقى قىسىمدا يېتەرلىك بوشلۇق بىلەن تۇرىدۇ.

## 5. ھەرىكەت ئۈنۈمى: سىلىقلىق ۋە سۈرئەت (Motion)

ئەينەك ۋە سۇيۇقلۇق سېزىمىنى بېرىش ئۈچۈن ھەرىكەتلەر قاتتىق ئەمەس، بەلكى **ئېلاستىك، يۇمشاق ۋە تەبىئىي** بولۇشى كېرەك.

### سىلىقلىق ئەگرى سىزىقى (Easing)
* **ئاساسىي يۇمشاق ھەرىكەت:** `cubic-bezier(0.22, 1, 0.36, 1)` (تېز باشلىنىپ، ناھايىتى سىلىق توختايدۇ)
* **ئېلاستىك قاڭقىش (ۋىكليۇچاتېل ۋە باسقاندا):** `cubic-bezier(0.34, 1.45, 0.64, 1)`

### سۈرئەت ئۆلچىمى (Duration)
* **مىكرو ئىنكاس (بېسىش، رەڭ ئۆزگىرىش):** `140ms` – `180ms`
* **ئادەتتىكى ھەرىكەت (چاشقان ئاپىرىش، ۋىكليۇچاتېل، بەتكۈچ):** `240ms` – `280ms`
* **كارتا ۋە كۆزنەك ئېچىلىش/يېپىلىش:** `320ms` – `380ms`

### ئۆزئارا تەسىر ھالەتلىرى (Interaction States)
* **چاشقان ئاپارغاندا (`:hover`):** ئېلېمېنت يۇقىرىغا `2px` كۆتۈرۈلىدۇ (`transform: translateY(-2px)`), كۆلەڭگە ۋە رەڭلىك نۇر ئۈنۈمى سەل كۈچىيىدۇ.
* **باسقاندا (`:active`):** ئېلېمېنت يېنىك ئىچىگە بېسىلىدۇ (`transform: scale(0.97)`), يۇقىرىقى نۇر سەل سۇسلىشىپ فىزىكىلىق كۇنۇپكا سېزىمى بېرىدۇ.
* **ھەرىكەتنى ئازايتىش (Accessibility):** سىستېما تەڭشىكىدە ھەرىكەت چەكلەنگەن ئىشلەتكۈچىلەر ئۈچۈن تۆۋەندىكى قائىدە چوقۇم قوشۇلىدۇ:
  ```css
  @media (prefers-reduced-motion: reduce) {
    * {
      animation-duration: 0.01ms !important;
      transition-duration: 0.01ms !important;
    }
  }
  ```
